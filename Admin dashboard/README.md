# Admin Dashboard

A responsive admin dashboard built with Bootstrap 5, Chart.js, and Animate.css. Features a sidebar with hamburger toggler for mobile, animated cards/tables, and a live chart.

## Features
- Responsive layout (desktop, tablet, mobile)
- Sidebar navigation (offcanvas on small screens)
- Animated cards and table rows
- Chart.js line chart for site traffic
- Bootstrap icons

## Usage
1. Open `index.html` in your browser.
2. No build step required.
3. Customize content, colors, or chart data in the HTML/CSS/JS as needed.

## Dependencies
- [Bootstrap 5](https://getbootstrap.com/)
- [Bootstrap Icons](https://icons.getbootstrap.com/)
- [Chart.js](https://www.chartjs.org/)
- [Animate.css](https://animate.style/)

## File Structure
- `index.html` — Main dashboard
- `assets/css/styles.css` — Custom styles
- `README.md` — Project info
